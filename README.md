# projeto-galeria-de-fotos
Galeria de Fotos é uma aplicação web desenvolvida com HTML, CSS e JavaScript que exibe imagens em um grid responsivo. Permite pesquisar fotos pelo nome, visualizar imagens em modal ampliado e interagir com efeitos visuais ao passar o mouse, oferecendo uma experiência simples e intuitiva.
##

**🛠 Tecnologias Utilizadas**

* HTML5 – Estrutura da aplicação

* CSS3 – Estilização, grid, responsividade e efeitos visuais

* JavaScript – Lógica da busca e controle do modal

* Font Awesome – Ícone de lupa na barra de busca

* Unsplash – Imagens públicas utilizadas no projeto

## 
**▶️ Como rodar a aplicação localmente**

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Clique duas vezes no arquivo `index.html`.

A aplicação será aberta automaticamente no navegador.
Não é necessário instalar dependências ou utilizar servidor local.
